what this is, and where to start

A welcome package for new joiners and a mid-panic reference for everyone else. Each module is one self-contained page covering a survival skill of the trade — your machine, your git history, your Python, your pipeline. New here? Read them in this order:

01 setup→ 02 python→ 03 git→ 04 ci→ 05 spark + companion: 06 ai

Each one stands alone — but they build on each other: get your machine working (setup), get fluent in the language (Python), put your work under version control (git), ship it safely (CI/CD), then scale it (Spark). The setup guide's inner loop becomes the CI guide's outer loop, and the CI guide's testing chapter is what the Spark guide assumes you know. 06 AI is the lone companion — it cuts across all of them: how to use AI tools on this work without leaking the client.

how the series works

WHAT EVERY MODULE CONTAINS Each guide follows the same shape so you always know where to look: a day-zero loop (the handful of steps you'll run every day), a mental model of how the thing actually works, "wanted posters" of the common mistakes, one settled holy war (the recurring debate, decided), a disaster-recovery section reachable from the panic button, and a boss-fight quiz to test yourself.
HOW TO CONTRIBUTE Each module is one self-contained index.html — no build step, no framework — deployed by GitHub Pages. Edit the file and open a PR; small PRs are welcome on any module. House style: mono headings, serif body. Full workflow and local-preview steps are in the README.
